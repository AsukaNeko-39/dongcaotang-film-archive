# 侗草堂｜影像创作与 AI 制作复盘

完整图文网页与原始资料。仓库公开，GitHub Pages 使用 main 分支根目录发布。

## 内容

- 故事与人物、影像语言、七段分镜时间线
- 五条样片记录与完整提示词
- 成片复盘、制作流程、培训正文和原文插图
- 九张原始积分记录、完整迭代地图
- 16 页原稿演示与图片放大

## 文件

纯静态网页，无需安装依赖或构建。首页 index.html，样式 styles.css，交互 app.js，完整资料 data.js，图片 assets/。原始 PPT 保持本地原版。
