# 侗草堂｜影像创作与 AI 制作复盘

完整图文网页与原始资料。仓库公开，GitHub Pages 使用 main 分支根目录发布。

## 内容

- 故事与人物、影像语言、七段分镜时间线
- 五条样片记录与完整提示词
- 成片复盘、制作流程、培训正文和原文插图
- 九张原始积分记录、完整迭代地图
- 16 页原稿演示与图片放大

## 文件

纯静态网页，无需安装依赖或构建。首页 index.html，样式 styles.css，交互 app.js，完整资料 data.js，图片 assets/。原始 PPT 保持本地原版。

## 来源

[飞书原始资料](https://my.feishu.cn/base/WbPVb688tawpxKsoa9HcmN2nnCf)

图片许可与出处列在网页“来源与图片说明”中。项目生成样片不作为真实历史摄影。

## 上下翻页

网页默认按页展示，支持滚轮、上下方向键、触屏和页码跳转。长篇原始资料在阅读窗口内完整保留。积分记录的上下预览保持同尺寸，计费字段以清晰文字呈现，并可放大核对对应原图。

导航与翻页栏采用自适应深浅配色的半透明玻璃效果。样片比较保留完整动作画幅，封面采用受限缩放；滚轮反向操作可立即返回上一页。

复盘四项以四象限等大图文卡片集中展示在同一页，图片统一为 16:9，并按主体调整取景，声音页说明避开人物，迭代地图提供约 16:9 的图内独立滚动窗口。网站共 17 页，16 页原稿仍单独完整保留。顶部圆点切换章节，底部中央可直接输入数字页码，右下角上下箭头翻页。

一次滚轮操作最多切换一页：滚动幅度、持续时间或追加力度都不触发第二页。结束本轮后再次滚动，才进行下一次切换。长图与长正文保持独立滚动。
